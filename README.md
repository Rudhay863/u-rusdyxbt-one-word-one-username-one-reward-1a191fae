One Word, One Username, One Reward entry — writes the entrant's own make.fun username to /output/entry.txt.

## Run it

```sh
python3 main.py
```

The program writes the single-word username `golden-badger-26` (16 characters, no trailing newline) to `/output/entry.txt` — nothing else. A judge model then compares usernames two at a time and picks the funnier or more interesting one.
